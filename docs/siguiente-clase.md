# Generación de la siguiente clase

Entrada humana mínima: `Genera la siguiente clase de <materia>`.

La planeación específica de la materia es la fuente de secuencia. Para Sistemas Distribuidos se usa `11QQnAbMCCoebc2o6Tm2_lROZvyfjFnVM89ZAcgBbr6I`, hoja `Planeación`, encabezado en fila 6. El motor no debe sustituirla por la planeación de Sistemas Operativos.

`resolverSiguienteClase(materia)` resuelve el paquete canónico y `generarSiguienteClase(params)` es el entrypoint remoto. Todos los recursos automáticos conservan DRAFT y las funciones creadoras existentes deben reutilizarse para evitar duplicar reglas.
